# Typed Service Guide

This guide explains how to use the Type-Safe Service feature (Typed Service) of the PocketBase Go Client.

## Overview

The PocketBase Go Client provides a **Typed Service** feature that allows you to perform CRUD operations in a type-safe manner. By using code generated via `pbc-gen`, you can receive results as specific struct types (e.g., `*models.Persons`) instead of `interface{}` or generic `*Record`, providing compilation-time safety and better IDE support (autocomplete).

## Prerequisites

1.  **Code Generation**: You must generate model codes using the `pbc-gen` tool.
    ```bash
    # Install pbc-gen
    curl -sL https://raw.githubusercontent.com/mrchypark/pocketbase-client/main/install.sh | sh

    # Export schema and generate models
    curl http://localhost:8090/api/collections > schema.json
    pbc-gen -schema schema.json -path models/models.gen.go -pkgname models
    ```

## Usage

### 1. Initialize Typed Service

Create a dedicated service for the collection you want to use. The service constructor is automatically generated in the format `New{CollectionName}Service`.

```go
package main

import (
    "context"
    "log"
    
    pocketbase "github.com/mrchypark/pocketbase-client"
    "your-project/models" // Package generated by pbc-gen
)

func main() {
    // 1. Create Client
    client := pocketbase.NewClient("http://127.0.0.1:8090")
    
    // 2. Authenticate (optional)
    client.WithAdminPassword(context.Background(), "admin@example.com", "password")

    // 3. Create Typed Service
    // The collection name ("persons") is automatically bound internally.
    personService := models.NewPersonsService(client)
    
    ctx := context.Background()

    // Now you can use Type-Safe CRUD operations!
}
```

### 2. CRUD Operations

#### Create (Create)

Use the generated struct constructor (`models.New{StructName}`) to create a new record object, set values, and save it.

```go
// Create a new record object
newPerson := models.NewPersons()
newPerson.SetName("John Doe") // Type-safe setter
newPerson.SetAge(30)

// Save to DB
// created is of type *models.Persons (not interface{})
created, err := personService.Create(ctx, newPerson, nil)
if err != nil {
    log.Fatal(err)
}
log.Printf("Created ID: %s", created.ID)
```

#### Read (GetOne / GetList)

The return values are typed structs. You don't need Type Assertion.

```go
// GetOne
person, err := personService.GetOne(ctx, "RECORD_ID", nil)
if err != nil {
    log.Fatal(err)
}
// Direct field access (via getter)
log.Printf("Name: %s", person.Name())


// GetList
list, err := personService.GetList(ctx, &pocketbase.ListOptions{
    Page:    1,
    PerPage: 10,
    Sort:    "-created",
})
if err != nil {
    log.Fatal(err)
}

// list.Items is [] *models.Persons
for _, p := range list.Items {
    log.Printf("Person: %s (%d)", p.Name(), p.Age())
}
```

#### Update (Update)

Retrieve an object, modify the necessary fields, and update it.

```go
// 1. Fetch
person, _ := personService.GetOne(ctx, "RECORD_ID", nil)

// 2. Modify
person.SetAge(31)

// 3. Update
updated, err := personService.Update(ctx, person.ID, person, nil)
if err != nil {
    log.Fatal(err)
}
```

#### Delete (Delete)

```go
err := personService.Delete(ctx, "RECORD_ID")
if err != nil {
    log.Fatal(err)
}
```

## Comparison with Dynamic API

| Feature | Typed Service (Recommended) | Dynamic API (`client.Records`) |
| :--- | :--- | :--- |
| **Return Type** | `*models.Persons` | `*pocketbase.Record` |
| **Field Access** | `person.Name()` (Getter) | `record.GetString("name")` |
| **Type Safety** | ✅ Compile-time Check | ❌ Runtime Check (Risk of typos) |
| **Collection Name** | Auto-binding | Must be passed as string every time |
| **IDE Support** | ✅ Autocomplete available | ❌ Autocomplete unavailable |

## Conclusion

Using **Typed Service** makes your code more robust and maintainable. It eliminates typos in field names and collection names, and makes refactoring easier.
