## Overview

The `TypedRecordService[T]` is a generic service that performs CRUD operations on PocketBase collections with full type safety. Unlike the dynamic `RecordService` which returns `*Record` (requiring runtime field access via `GetString`, `GetInt`, etc.), `TypedRecordService` returns your specific generated struct types.

### Key Benefits

| Benefit | Description |
|---------|-------------|
| **Compile-time Safety** | Type errors caught at compile time, not runtime |
| **IDE Autocomplete** | Full autocomplete for struct fields and methods |
| **Refactoring** | Safe renaming with IDE refactoring tools |
| **No Type Assertions** | No need for `record.GetString("field")` or type switches |
| **Generated Helpers** | Constructor, setters, and getter methods auto-generated |

### Why It Works

The service handles JSON unmarshaling correctly by:

1. **Receiving `*Record`** from the API (via `RecordService.GetList`)
2. **Converting each item** using `convertRecord[T]()` function
3. **Marshal/Unmarshal cycle** to populate all fields into the concrete type

```go
// records.go:296-323
func convertRecord[T any](rec *Record) (*T, error) {
    // Case 1: T is *Record (passthrough)
    if ptr, ok := any(&t).(**Record); ok {
        *ptr = rec
        return &t, nil
    }

    // Case 2: T implements RecordModel (generated types)
    if model, ok := any(&t).(RecordModel); ok {
        model.SetID(rec.ID)
        model.SetCollectionID(rec.CollectionID)
        model.SetCollectionName(rec.CollectionName)

        // Marshal record to JSON and unmarshal into the model
        data, err := json.Marshal(rec)
        if err != nil {
            return nil, fmt.Errorf("failed to marshal record: %w", err)
        }
        if err := json.Unmarshal(data, &t); err != nil {
            return nil, fmt.Errorf("failed to unmarshal into %T: %w", t, err)
        }
        return &t, nil
    }

    return nil, fmt.Errorf("cannot convert Record to %T", t)
}
```

## Interface Requirements

For a type `T` to be used with `TypedRecordService[T]`, it must implement the following interfaces:

### 1. BaseModel (Required)

All models must implement `BaseModel` to provide access to system fields:

```go
type BaseModel interface {
    GetID() string
    GetCollectionName() string
}
```

### 2. RecordModel (Required for most operations)

Generated types should implement `RecordModel` for population from API responses:

```go
type RecordModel interface {
    BaseModel
    SetID(id string)
    SetCollectionID(id string)
    SetCollectionName(name string)
}
```

### 3. Mappable (Required for Create/Update)

For serializing data when creating or updating records:

```go
type Mappable interface {
    ToMap() map[string]any
}
```

### Generated Implementation Example

The `pbc-gen` tool automatically generates all required interfaces (`cmd/pbc-gen/template.go.tpl:212-216`):

```go
// This is AUTO-GENERATED by pbc-gen

type Post struct {
    ID             string         `json:"id"`
    CollectionID   string         `json:"collectionId"`
    CollectionName string         `json:"collectionName"`
    Created        types.DateTime `json:"created"`
    Updated        types.DateTime `json:"updated"`
    Title          string         `json:"title"`
    Content        string         `json:"content"`
    Published      bool           `json:"published"`
}

// BaseModel interface
func (m *Post) GetID() string             { return m.ID }
func (m *Post) GetCollectionName() string { return "posts" }

// RecordModel interface
func (m *Post) SetID(id string)           { m.ID = id }
func (m *Post) SetCollectionID(id string) { m.CollectionID = id }
func (m *Post) SetCollectionName(name string) { m.CollectionName = name }

// Mappable interface
func (m *Post) ToMap() map[string]any {
    return map[string]any{
        "title":     m.Title,
        "content":   m.Content,
        "published": m.Published,
    }
}

// Interface compliance check (compile-time verification)
var _ pocketbase.RecordModel = (*Post)(nil)
```

## Service Creation

### Method 1: Using Generated Helper (Recommended)

The code generator creates helper functions for each collection:

```go
// Generated in models.gen.go
func NewPostService(client *pocketbase.Client) *pocketbase.TypedRecordService[Post] {
    return pocketbase.NewTypedRecordService[Post](client, "posts")
}

// Usage
postService := NewPostService(client)
```

### Method 2: Manual Creation

```go
// Manual service creation
postService := pocketbase.NewTypedRecordService[Post](client, "posts")
```

### Method 3: Using NewXxx() Constructor

Generated types also include a constructor:

```go
// Generated: func NewPost() *Post
post := models.NewPost()
post.SetTitle("My Post")
post.SetContent("Content here")
```

## CRUD Operations

### Create

Create a new record using a generated struct:

```go
// Method 1: Using generated constructor
newPost := models.NewPost()
newPost.SetTitle("My First Post")
newPost.SetContent("Hello, World!")
newPost.SetPublished(true)

// Method 2: Direct struct initialization
newPost := &Post{
    Title:     "My First Post",
    Content:   "Hello, World!",
    Published: true,
}

created, err := postService.Create(ctx, newPost, nil)
if err != nil {
    log.Fatalf("Create failed: %v", err)
}

fmt.Printf("Created: ID=%s, Title=%s\n", created.GetID(), created.Title())
```

**Return Type**: `*Post` (not `interface{}`)

---

### Read One (GetOne)

Retrieve a single record by ID:

```go
post, err := postService.GetOne(ctx, "RECORD_ID", nil)
if err != nil {
    log.Fatalf("GetOne failed: %v", err)
}

// Access fields via generated getters
fmt.Printf("Title: %s\n", post.Title())
fmt.Printf("Created: %s\n", post.Created)
fmt.Printf("Published: %v\n", post.Published())
```

**Return Type**: `*Post`

---

### Read List (GetList)

Retrieve a paginated list of records:

```go
result, err := postService.GetList(ctx, &pocketbase.ListOptions{
    Page:    1,
    PerPage: 10,
    Filter:  "published = true",
    Sort:    "-created",
    Expand:  "author",
    Fields:  "id,title,author.name,created",
})
if err != nil {
    log.Fatalf("GetList failed: %v", err)
}

// Access pagination metadata
fmt.Printf("Total: %d items (Page %d of %d)\n", 
    result.TotalItems, result.Page, result.TotalPages)

// Access typed items
for i, post := range result.Items {
    fmt.Printf("%d. %s\n", i+1, post.Title())
}
```

**TypedListResult Structure** (`records.go:285-291`):

```go
type TypedListResult[T any] struct {
    Page       int    `json:"page"`
    PerPage    int    `json:"perPage"`
    TotalItems int    `json:"totalItems"`
    TotalPages int    `json:"totalPages"`
    Items      []*T   `json:"items"`  // ✅ Concrete pointer type
}
```

### Read All (GetAll)

Retrieve ALL records with automatic pagination:

```go
// Fetches all pages automatically
allPosts, err := postService.GetAll(ctx, &pocketbase.ListOptions{
    Filter: "published = true",
    Sort:   "-created",
})
if err != nil {
    log.Fatalf("GetAll failed: %v", err)
}

fmt.Printf("Total posts: %d\n", len(allPosts))
for _, post := range allPosts {
    fmt.Printf("- %s\n", post.Title())
}
```

**Return Type**: `[]*Post`

> **Note**: `GetAll` internally calls `GetList` repeatedly until all pages are fetched.


**Return Type**: `*Post` (the updated record)

## Relation Fields

### Expand Relations in Query

Use `Expand` option to automatically load related records:

```go
// Get post with expanded author relation
post, err := postService.GetOne(ctx, "RECORD_ID", &pocketbase.GetOneOptions{
    Expand: "author",  // Load the author record
})
if err != nil {
    log.Fatalf("GetOne failed: %v", err)
}

// Access author ID (if field exists in Post struct)
authorID := post.GetString("author")

// Or use the expanded data if Post has an Author field
// Note: Generated types typically use GetString for relation IDs
```

### Manual Relation Loading

For type-safe relation loading, create services for both collections:

```go
// Create services for both collections
postService := pocketbase.NewTypedRecordService[Post](client, "posts")
authorService := pocketbase.NewTypedRecordService[Author](client, "authors")

// Fetch post
post, err := postService.GetOne(ctx, "POST_ID", nil)
if err != nil {
    log.Fatalf("Failed to get post: %v", err)
}

// Fetch author manually
author, err := authorService.GetOne(ctx, post.GetString("author"), nil)
if err != nil {
    log.Fatalf("Failed to get author: %v", err)
}

fmt.Printf("%s wrote: %s\n", author.Name(), post.Title())
```

## Complete Example

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    pocketbase "github.com/mrchypark/pocketbase-client"
    "github.com/yourproject/models"
)

func main() {
    ctx := context.Background()

    // 1. Create client
    client := pocketbase.NewClient("http://127.0.0.1:8090")

    // 2. Authenticate
    _, err := client.WithAdminPassword(ctx, "admin@example.com", "password123")
    if err != nil {
        log.Fatalf("Auth failed: %v", err)
    }

    // 3. Create service
    postService := pocketbase.NewTypedRecordService[models.Post](client, "posts")

    // === CREATE ===
    fmt.Println("=== Create ===")
    newPost := models.NewPost()
    newPost.SetTitle("First Post")
    newPost.SetContent("Hello, World!")
    newPost.SetPublished(true)
    newPost.SetViewCount(0)

    created, err := postService.Create(ctx, newPost, nil)
    if err != nil {
        log.Fatalf("Create failed: %v", err)
    }
    fmt.Printf("Created: ID=%s, Title=%s\n", created.GetID(), created.Title())

    // === READ ONE ===
    fmt.Println("\n=== Read One ===")
    post, err := postService.GetOne(ctx, created.GetID(), nil)
    if err != nil {
        log.Fatalf("GetOne failed: %v", err)
    }
    fmt.Printf("Title: %s\n", post.Title())
    fmt.Printf("Views: %.0f\n", post.ViewCount())

    // === UPDATE ===
    fmt.Println("\n=== Update ===")
    post.SetViewCount(post.ViewCount() + 1)
    post.SetTitle("Updated Title")

    updated, err := postService.Update(ctx, post.GetID(), post, nil)
    if err != nil {
        log.Fatalf("Update failed: %v", err)
    }
    fmt.Printf("Updated: %s (Views: %.0f)\n", updated.Title(), updated.ViewCount())

    // === READ LIST ===
    fmt.Println("\n=== Read List ===")
    result, err := postService.GetList(ctx, &pocketbase.ListOptions{
        Page:    1,
        PerPage: 10,
        Filter:  "published = true",
        Sort:    "-created",
    })
    if err != nil {
        log.Fatalf("GetList failed: %v", err)
    }
    fmt.Printf("Found %d posts:\n", result.TotalItems)
    for i, p := range result.Items {
        fmt.Printf("  %d. %s (%.0f views)\n", i+1, p.Title(), p.ViewCount())
    }

    // === READ ALL ===
    fmt.Println("\n=== Read All ===")
    allPosts, err := postService.GetAll(ctx, &pocketbase.ListOptions{
        Filter: "published = true",
    })
    if err != nil {
        log.Fatalf("GetAll failed: %v", err)
    }
    fmt.Printf("Total published posts: %d\n", len(allPosts))

    // === DELETE ===
    fmt.Println("\n=== Delete ===")
    err = postService.Delete(ctx, post.GetID())
    if err != nil {
        log.Fatalf("Delete failed: %v", err)
    }
    fmt.Println("Deleted successfully")

    fmt.Println("\n=== Done ===")
}
```

## Comparison with Dynamic API

| Feature | TypedRecordService (Recommended) | Dynamic API (`client.Records`) |
|---------|----------------------------------|-------------------------------|
| **Return Type** | `*models.Post` | `*pocketbase.Record` |
| **Field Access** | `post.Title()` (generated getter) | `record.GetString("title")` |
| **Type Safety** | ✅ Compile-time check | ❌ Runtime check only |
| **IDE Support** | ✅ Full autocomplete | ❌ No autocomplete |
| **Collection Binding** | ✅ Automatic | ❌ Manual string every call |
| **Code Completion** | ✅ All methods available | ❌ Limited to interface |
| **Error Detection** | At compile time | At runtime |
| **Boilerplate** | ✅ Minimal | ❌ More code needed |

## Troubleshooting

### Issue: "cannot convert Record to T"

**Error**:
```
pocketbase: cannot convert Record to *models.Post (must implement RecordModel)
```

**Cause**: Your model doesn't implement `RecordModel` interface.

**Solution**: Ensure your type implements all required methods:

```go
// Required methods
func (m *Post) GetID() string             { return m.ID }
func (m *Post) GetCollectionName() string { return "posts" }
func (m *Post) SetID(id string)           { m.ID = id }
func (m *Post) SetCollectionID(id string) { m.CollectionID = id }
func (m *Post) SetCollectionName(name string) { m.CollectionName = name }
func (m *Post) ToMap() map[string]any {
    return map[string]any{
        "title": m.Title,
        // ... other fields
    }
}

// Compile-time verification
var _ pocketbase.RecordModel = (*Post)(nil)
```

### Issue: "json: cannot unmarshal object into Go value of type"

**Cause**: Using `Service[T Model]` instead of `TypedRecordService[T]`. The `Service` type has an interface constraint issue with JSON unmarshaling.

**Solution**: Use `TypedRecordService` instead:

```go
// ❌ Avoid this (has issues with interface slice unmarshaling)
service := pocketbase.NewService[MyModel](client, "collection")

// ✅ Use this (correct)
service := pocketbase.NewTypedRecordService[MyModel](client, "collection")
```

### Issue: Fields not populated

**Cause**: Missing `UnmarshalJSON` or incomplete `ToMap` implementation.

**Solution**: Generated types include proper JSON handling. If using manual types, ensure:

1. All JSON tags are correct
2. `ToMap()` includes all fields for Create/Update
3. `Set*` methods update the struct fields

## Summary

`TypedRecordService` provides a robust, type-safe way to interact with PocketBase:

1. **Generate models** with `pbc-gen`
2. **Create service** with `NewXxxService(client)`
3. **Use CRUD operations** with full type safety
4. **Access fields** via generated getters
5. **Get compile-time errors** instead of runtime surprises

For best results, always use the code generator (`pbc-gen`) to ensure your types correctly implement all required interfaces.
